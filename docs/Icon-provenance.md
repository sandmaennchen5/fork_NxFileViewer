# Icon provenance

The existing icon artwork is retained without modification.

## Verified repository history

The table records each file's first addition found by following renames in the
local upstream Git history, plus the SHA-256 of the currently retained file.
The commit contributor is **not** necessarily the original artwork creator.
A commit reference establishes repository provenance, not a third-party license.

The upstream [icon README at commit 26fc13c](https://github.com/Myster-Tee/NxFileViewer/blob/26fc13ca83fd4a857cb178f8390190385564ddb2/src/NxFileViewer/Styling/Icons/README.md)
states that some icons were downloaded as SVG from
[Iconfinder](https://www.iconfinder.com/) and tree icons were edited with
[Method Draw](https://editor.method.ac/). It does not identify the corresponding
files, original authors, asset pages or individual licenses.
The checked SVG files contain no author or license metadata.

## Unresolved attribution

Individual third-party artwork authors and licenses remain unverified.
The repository's GPL text does not establish an individual third-party icon
license. No MIT, GPL, public-domain or other license is inferred for these assets.
To resolve an entry, record its original asset URL, creator, exact license and
any required attribution, with evidence matching the retained artwork.
